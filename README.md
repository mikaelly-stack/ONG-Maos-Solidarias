# ONG Mãos Solidárias

Projeto web desenvolvido para uma atividade acadêmica.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git

## Estrutura

- `html/`: páginas da aplicação
- `css/`: estilos
- `js/`: lógica JavaScript e módulos
- `imagens/`: imagens utilizadas

## Instalação local

1. Clone o repositório:
   `git clone https://github.com/mikaelly-stack/ONG-Maos-Solidarias.git`

2. Acesse a pasta:
   `cd ONG-Maos-Solidarias`

3. Abra o arquivo `html/index.html` no navegador.

O projeto não possui dependências externas nem processo de build, pois utiliza HTML5, CSS3 e JavaScript.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão, seguindo uma organização baseada em GitFlow.

- `main`: versão estável.
- `develop`: desenvolvimento.
- `feature/`: novas funcionalidades ou alterações.
- `hotfix/`: correções urgentes.

São utilizados Conventional Commits e versionamento semântico por meio de tags, como `v1.0.0`.
